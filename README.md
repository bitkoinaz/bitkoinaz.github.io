# Exclusive Offers — BitkoinAz

Статическая страница реферальных ссылок для GitHub Pages. Сайт открывается с корня ветки `main`: [https://bitkoinaz.github.io](https://bitkoinaz.github.io). Сборка не нужна.

Тексты, ссылки и порядок бирж лежат в [`links.json`](links.json). Страница загружает этот файл сама.

## Как отредактировать links.json

1. Откройте `links.json` в репозитории на GitHub.
2. Нажмите иконку карандаша (**Edit this file**).
3. Измените текст, ссылку или порядок бирж.
4. Нажмите **Commit changes**.

Страница обновится примерно через минуту. Если видите старую версию, обновите вкладку.

Файл должен остаться корректным JSON: двойные кавычки, запятые между блоками и без запятой после последнего блока.

- `title`, `subtitle`, `footer` — заголовок, подзаголовок и текст внизу.
- `featured` — `id` биржи, которая показывается большой карточкой сверху.
- `bonus` — короткая строка под названием.
- `highlight` — точный фрагмент `bonus`, он рисуется зелёным. Можно оставить `""`.
- `badge` — маленькая метка рядом с названием. Пустая строка прячет метку.

Порядок объектов в `exchanges` — это порядок на странице. Биржа из `featured` поднимается наверх отдельной карточкой и в общем списке не повторяется.

Если `links.json` не загрузится, страница покажет запасную копию из `index.html`. Для обычных правок достаточно менять `links.json`.

## Как добавить биржу

Скопируйте один объект в массиве `exchanges` и вставьте его в нужное место:

```json
{
  "id": "example",
  "name": "Example",
  "url": "https://example.com/",
  "bonus": "Регистрация + бонус для новых пользователей",
  "highlight": "бонус",
  "badge": ""
}
```

`id` — латиница без пробелов. Для `bybit`, `binance`, `mexc`, `bitget` и `okx` стоят цветные значки. У новой биржи будет буква на цветном фоне.

Чтобы сделать биржу главной, запишите её `id` в поле `featured`.

## Файл .nojekyll

В корне репозитория лежит пустой файл `.nojekyll`. Он отключает Jekyll на GitHub Pages, чтобы `links.json` и остальные файлы отдавались как есть. Не удаляйте его.
